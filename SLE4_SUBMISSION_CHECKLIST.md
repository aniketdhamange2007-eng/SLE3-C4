# SLE-4 Submission Checklist

Based on the SLE-4 student guideline for 02AML204.

- [ ] Cover details: PRN, name, division, date, optional GitHub link.
- [ ] One complete ADR with title, status, date, context, decision, alternatives, rationale, consequences, and optional references.
- [ ] Rationale includes actual SLE-2 profiling numbers and relevant SLE-3 design reasons.
- [ ] Short summary of SLE-1 through SLE-3.
- [ ] Honest AI Contribution Note stating what AI helped with and what the student did.
- [ ] Optional viva preparation notes.
- [ ] Keep the document to 2–3 pages; maximum 4 pages.
- [ ] Save/export the final submission as a Word or PDF file named according to the guideline, e.g. `SLE4_25UAM002.docx`.
- [ ] Upload the final Word/PDF file to the correct Moodle SLE-4 assignment.
- [ ] Prepare to explain the decision, rejected alternatives, profiling results, C4 Container diagram, scalability, and AI contribution.

**Important:** These are editable drafts. The required Moodle submission is one Word or PDF file. Verify the actual SLE-2 measurements and code before submitting; do not submit placeholders as evidence.
